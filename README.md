Supplementary material for the article
“Identifying the potential of rain gardens to support urban insect communities: assessing co-benefits to prevent ecosystem disservices”

This repository contains the following files:

REVIEW_Supplementary_Material_JEM.doc – Includes Supplementary Tables 1 and 2, Supplementary Figure 1, 2 and 3, cited in the article. Supplementary Table 1 provides a description of the explanatory variables, and Supplementary Table 2 defines the model structure, statistical families, and R packages used. FS1 is a representation of the insects sampling methods; FS2 is the correlation matrix of explanatory variables; and FS3 is a aerial view of all sampled buffers. 

Supplementary_Material_3.csv – Dataset containing morphotypes, taxonomic identifications of sampled individuals, and sampling locations (rain garden and zone).

dados_NMDS_v2.csv – Input dataset for the NMDS and PERMANOVA analyses described in the script.

Models_data_chapter_II_v2.csv – Input dataset containing response and explanatory variables used in the statistical models described in the script.

script_models_chapter_II_JWA_v3.R – R script containing the statistical analyses performed in the study.

METEOROLOGICAL_CONDITIONS+SM_4.xlsx - Meteorological data on precipitation, humidity, and temperature for each sampling date, obtained from the weather station closest to each rain garden.
